# CRYPTEX Frontend

The CRYPTEX frontend is a Next.js application that provides the user-facing interface for the platform.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Current Scope

The frontend is being developed alongside the backend. Authentication screens, dashboard workflows, notifications, and profile experiences are being introduced incrementally.

The current landing page describes the implemented backend foundation rather than pretending unfinished product functionality is complete.

## Production Build

```bash
npm run build
npm run start
```
